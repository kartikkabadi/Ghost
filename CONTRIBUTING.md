# Contributing to Ghost

Thanks for your interest in contributing.

## Getting Started

1. Fork the repository.
2. Clone your fork and create a feature branch.
3. Copy `.env.example` to `.env` and add your own API keys.
4. Install dependencies and run the dev server.
5. Make your changes and ensure the project still builds.

## Reporting Issues

- Use the issue tracker for bugs, feature requests, and documentation improvements.
- For security issues, see [SECURITY.md](./SECURITY.md).

## Pull Request Guidelines

- Keep changes focused and well-scoped.
- Follow the existing code style in Rust and TypeScript files.
- Preserve comments and provenance information.
- Update relevant documentation if your change affects public interfaces.
- Ensure `cargo check` and the Next.js build pass before submitting.

## Code of Conduct

Be respectful, constructive, and mindful that Ghost is a research tool. Contributions that enable misuse or bypass the [ETHICAL_USE.md](./ETHICAL_USE.md) policy will not be accepted.
